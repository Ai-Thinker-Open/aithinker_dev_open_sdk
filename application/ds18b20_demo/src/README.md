# 🌡️ DS18B20 单总线温度采集示例 (AIIO 平台)

本项目演示如何在 AIIO 平台上驱动 DS18B20 单总线温度传感器，读取当前温度并通过日志系统打印输出。

---

## ✅ 功能概述

- 初始化 GPIO 引脚，配置为 DS18B20 所需的输入输出模式。
- 通过 **单总线协议** 完成初始化、写命令、读温度。
- 支持读取负温度。
- 输出温度值（带小数点），单位为摄氏度。
- 使用 `EasyLogger` 记录温度值变化。

---

## 📁 文件结构

| 文件名               | 描述                       |
|----------------------|----------------------------|
| `main.c`             | 主函数，读取并打印温度     |
| `module_single.h/c`  | 单总线协议通信接口封装     |
| `aiio_adapter_include.h` | AIIO 平台适配封装      |
| `hello_h2.h`         | 自定义头文件（未详列内容） |

---

## 🧰 硬件需求

- MCU（支持 AIIO 平台）
- DS18B20 温度传感器
- 一个 GPIO 引脚连接 DS18B20 的 **DQ 数据线**
- 上拉电阻（4.7kΩ 推荐）

---

## ⚙️ 配置说明

以下配置通过构建系统或头文件定义：

| 宏 | 说明 |
|----|------|
| `CONFIG_GPIO_DS18B20_PORT` | DS18B20 所连接 GPIO 的端口号 |
| `CONFIG_GPIO_DS18B20_PIN`  | DS18B20 所连接 GPIO 的引脚号 |
| `CONFIG_GPIO_DS18B20_DELAY` | 单总线协议中的微秒延迟时间（默认为 105） |
