# 简介

该demo主要是使用ble对接HarmonyOs。

# 环境搭建

参考主工程的readme，搭建开发环境后可以正常 demo 例程表示环境搭建完毕

# 编译

1. 进入sdk根目录

2. 执行 ./build.sh platform harmonyos_ble_demo menuconfig ,不用修改直接退出，生成默认config

   eg：./build.sh bl602 harmonyos_ble_demo menuconfig

3. 执行 ./build.sh platform harmonyos_ble_demo cn debug 开始编译

   eg：./build.sh bl602 harmonyos_ble_demo cn debug
